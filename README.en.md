# ⏳ Steam Hours Booster(Linux & Windows)

A lightweight and convenient desktop application built on **Avalonia UI** and **.NET 10**, designed to manage your Steam status and simulate playtime (farming hours) for multiple games simultaneously.

❗❗**THE APP DOES NOT SHARE YOUR DATA WITH THIRD PARTIES**

❗❗**THE APPLICATION WORKS WITH STEAM SERVERS**

---

## 🖥 Supported Systems

The project is cross-platform and has been tested on:
* **Linux** (including **Raspberry Pi** distributions with X11 / Wayland)
* **Windows 11** (x64)

---

## 🪟 Running on Windows

1. Download or clone the project repository.
2. Navigate to the build folder:
   `\steamHoursLinux\steamHoursLinux\bin\Release\net10.0`
3. Run the executable **`steamHoursLinux.exe`**.
