# ⏳ Steam Hours (Linux & Windows)

Легкое и удобное десктопное приложение на базе **Avalonia UI** и **.NET 10**, предназначенное для управления статусом и симуляции времени в играх Steam (фарминг часов) одновременно для нескольких приложений.

---

## 🖥 Поддерживаемые системы

Проект кроссплатформенный и тестировался на следующих ОС:
* **Linux** (включая дистрибутивы для **Raspberry Pi** с окружением X11 / Wayland)
* **Windows 11** (x64)

---

# Что дальше?
